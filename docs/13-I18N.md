# Internationalisation

## Configuration

### Langues supportees
- **FR** (francais) — langue par defaut
- **EN** (anglais)

### Fichier principal
`src/lib/i18n.ts`

### Detection
- URL prefix : non (single locale)
- Cookie : `locale=fr|en`
- Navigator : `navigator.language`
- Default : `fr`
