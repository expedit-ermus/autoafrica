# Documentation AutoAfrique

Documentation de référence du projet AutoAfrique — ERP SaaS + marketplace B2B/B2C de pièces détachées automobile en Afrique de l'Ouest (Côte d'Ivoire prioritaire), Next.js 16, React 19, Prisma, TypeScript, SQLite (libSQL).
